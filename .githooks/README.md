# Git hooks

새로 클론한 뒤 한 번만 실행하면 활성화됩니다 (`core.hooksPath`는 로컬 설정이라 클론에 따라오지 않습니다):

```sh
git config core.hooksPath .githooks
```

## pre-commit — PNG 자동 압축

스테이징된 PNG를 커밋 전에 256색 팔레트로 양자화합니다. 커밋 `384f9831`에서
저장소 전체(1.1GB → 556MB)에 적용한 것과 동일한 기준입니다.

- **PSNR ≥ 40 dB 이고 실제로 더 작아질 때만** 교체합니다. 히트맵·사진처럼
  그라데이션이 많은 이미지는 밴딩이 생기므로 게이트에 걸려 원본이 유지됩니다.
- 파일명은 바꾸지 않으므로 포스트의 이미지 참조는 그대로 동작합니다.
- 이미 압축된 파일을 다시 커밋해도 바이트가 동일해 손실이 누적되지 않습니다.
- unstaged 변경이 있는 파일은 건드리지 않고 건너뜁니다.
- ImageMagick(`magick`)이 없으면 경고만 출력하고 통과시킵니다.

### 옵션

| 환경변수 | 기본값 | 설명 |
|---|---|---|
| `SKIP_PNG_COMPRESS=1` | — | 이번 커밋만 압축 건너뛰기 |
| `PNG_MIN_PSNR` | `40` | 품질 게이트 (dB). 낮추면 더 줄지만 밴딩 위험 |
| `PNG_JOBS` | `8` | 병렬 처리 수 |

```sh
SKIP_PNG_COMPRESS=1 git commit -m "원본 화질 그대로 유지"
```
